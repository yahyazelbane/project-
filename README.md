# CampusFlow — Gestion des étudiants

Petit projet React pour un exercice de gestion d'étudiants. Il fonctionne sans compte, serveur ou base de données : les exemples et les modifications sont enregistrés dans le stockage local du navigateur.

## Lancer le projet

Installez les dépendances avec npm install, puis lancez le serveur avec npm run dev.

## Fonctionnalités

- Liste avec quelques étudiants d'exemple
- Ajout, modification et suppression
- Recherche par nom, e-mail ou filière
- Filtre par niveau
- Export de la liste affichée en CSV
- Réinitialisation des données d'exemple

Les données restent dans le navigateur utilisé pour le projet. Elles ne sont pas partagées entre appareils. Le bouton **Réinitialiser** remet les étudiants d'exemple.
